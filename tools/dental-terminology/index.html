Using the dictionary

Clear terminology for cross-border procurement

Can I search in Arabic or Turkish?

Yes. The same search box checks the English, Turkish and Arabic form of every entry.

Are these product specifications?

No. The dictionary helps identify terminology; it does not assert dimensions, materials or clinical indications for a particular product.

How should I request an exact instrument?

Include the manufacturer and catalogue code whenever possible, then use the trilingual term to clarify the instrument family.
